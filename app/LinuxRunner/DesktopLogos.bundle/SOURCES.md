# Desktop environment logos

Shown only to identify each desktop in LinuxRunner's desktop picker.
The marks are trademarks of their respective owners; no endorsement is implied.

| File | Source |
|---|---|
| linuxrunner.png | LinuxRunner's own app icon (`app/Assets.xcassets/LinuxRunnerAppIcon.appiconset`, 1024 px, scaled to 256 px) |
| gnome.png | Papirus icon theme 20240201 (GPL-3.0), `Papirus/64x64/apps/desktop-environment-gnome.svg`, Ubuntu 24.04 `papirus-icon-theme` |
| plasma.png | Papirus icon theme 20240201 (GPL-3.0), `Papirus/64x64/apps/desktop-environment-kde.svg` |
| lxqt.png | Papirus icon theme 20240201 (GPL-3.0), `Papirus/64x64/apps/desktop-environment-lxqt.svg` |
| xfce.png | Papirus icon theme 20240201 (GPL-3.0), `Papirus/64x64/apps/desktop-environment-xfce.svg` |

SVGs were rasterized to 256x256 PNG with transparency (AppKit). Desktops with
no logo in the icon theme (i3, Wayfire, Hyprland,
Enlightenment) are drawn by the app as symbol tiles, not imitations of a logo.
