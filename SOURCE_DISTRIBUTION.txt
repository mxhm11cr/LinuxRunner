LinuxRunner 1.1.0 (Build 900) source distribution

The matching release source asset is LinuxRunner-1.1.0-source.tar.gz.
It must include the application source, build scripts, active pinned submodules,
GPU integration/dependency source and patches, matching bundled-Alpine recipes
and source inputs, and matching terminal renderer source. Retain each component's
notices and the source manifest identifying all included revisions.

GitHub automatic archives omit submodule contents and external graphics sources.
They are not substitutes for the dependency-inclusive corresponding-source asset.
See docs/BUILDING.md, THIRD_PARTY_NOTICES.md and licenses/gpu-dependencies.json.

The IPA is ad-hoc signed without Apple provisioning. Ordinary device installation
requires a compatible signing/provisioning method. No credentials or profiles
belong in the source or notices assets. JIT activation is optional.
